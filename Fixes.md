# (Wifi)

As explained in the [Unsupported List](https://github.com/QuakedK/Service-Destroyer/blob/main/Unsupported%20Features.md), Wi-Fi is natively unsupported/disabled. However, it can be easily re-enabled by running the [Wi-Fi Fixer](https://github.com/QuakedK/Oneclick/blob/main/Downloads/Revert/Wifi%20Fixer%20V3.5.bat).
